# 📅 Agendamento de Transferências

Este projeto tem como objetivo realizar o **agendamento de transferência** de valores para datas futuras.

## 🚀 Tecnologias Usadas

- 🖥️ **Visual Studio Code**
- 🌐 **HTML**
- 🎨 **Bootstrap** (versão 5.3.3)
- 🟢 **Angular** (versão 16.2.0)
- ⚙️ **Node.js** (versão 22.14.0)
- 🟡 **TypeScript** (versão 5.1.3)
- 🔵 **Banco de Dados H2**

## 📌 Funcionalidades

✔️ **Cadastro de Agendamento**  
✔️ **Consulta da Lista de Agendamentos Realizados**  

## 🔧 Como Rodar o Projeto

1️⃣ **Instalar as dependências:**  
```sh
npm install

2️⃣ **Executar o servidor:**
ng serve

3️⃣ Acessar no navegador:
Abra http://localhost:4200/ no navegador para visualizar o projeto.
